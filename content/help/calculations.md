# 계산 방식
> 언제 쓰나: 화면의 진척률·달성률·집행률·우선순위·산출근거 금액·규칙 판정이 어떻게 나온 숫자인지 확인할 때 봅니다.

파생 값은 저장하지 않고 읽을 때마다 계산합니다. 반올림은 표시 단계에서만 합니다(SOT §6.1 P-8) — 중간값을 먼저 반올림하면 숫자가 어긋납니다.

## 진척률 (SOT §6.1)
작업 → 연차 → 단계 → 과제, 4단계로 올라갑니다.
- **리프 작업**: 완료면 100, 아니면 입력한 진척률. **부모 작업**은 자식을 예상시간으로 가중 평균합니다(예상시간이 없으면 1). 수동 모드면 입력값을 그대로 씁니다.
- **연차** = 루트 작업의 예상시간 가중 평균. 작업이 없으면 0이고 분모에는 남습니다(P-13).
- **단계·과제** = 연차·단계의 예산 가중 평균(설정의 진척률 가중 기준이 예산일 때). 연차 예산에 양수가 하나도 없으면 균등으로 폴백합니다(P-9).
- 표시는 소수 1자리 고정, 계산 불가는 `N/A`.
- 부록 B.1: 자식이 40h·100%와 60h·30%이면 부모는 `(100×40 + 30×60) / 100 = 58`. 같은 연차에 50h·0% 루트가 더 있으면 연차는 `5800 / 150 = 38.666…`. 1차년도 100(예산 2억)과 2차년도 38.666…(예산 4억)의 예산 가중은 `59.111…` → 표시 59.1.

## 성과목표 달성률 (SOT §6.2)
- 지표 = `실적 건수 / 목표 건수 × 100`. 100 초과를 허용합니다(D-2).
- 과제 전체 = `Σ실적 / Σ목표`, 지표별 가중 없음. 목표가 0이면 `N/A`, 실적만 있으면 "목표 외 달성"(D-1·D-5).
- 부록 B.3: 목표 4·6·2에 실적 3·7·0이면 지표별 75 / 116.7 / 0, 전체 `10 / 12 = 83.3`.

## 기술목표 달성률 (SOT §6.3)
현재값은 가장 최신 날짜의 측정 기록입니다. 시작점은 국내 기준값이며 없으면 0입니다(T-2). 결과는 0~100으로 자릅니다(T-1).
- **높을수록 좋음**: `(현재 − 시작점) / (목표 − 시작점) × 100`. 목표 = 시작점이면 현재 ≥ 목표일 때 100, 아니면 0.
- **낮을수록 좋음**: `(시작점 − 현재) / (시작점 − 목표) × 100`. **국내 기준값이 없으면 `N/A`** — 감소율의 출발점이 없기 때문입니다.
- **정확히 맞춤**: 목표의 ±5% 안이면 100, 아니면 0.
- 과제 전체 = 비중 가중 평균. 미측정은 0으로 넣고 분모에 남깁니다.
- 부록 B.2: 정확도(국내 75, 목표 90, 현재 85)는 `66.666…`, 지연시간(국내 200, 목표 50, 현재 80)은 `80.0`, 미측정 항목은 0. 비중 50·30·20이면 `57.333…` → 표시 57.3. 66.666…을 66.7로 먼저 반올림하면 57.4가 나오는데 이는 틀린 값입니다.

## 집행률 (SOT §6.4)
- 비목 = `집행액 합 / 예산 × 100`. 연차·과제는 합계끼리 나눕니다 — 비목 집행률의 평균이 아닙니다.
- 예산이 0이면 `N/A`, 그런데 집행이 있으면 "예산 외 집행" 경고(B-1). 100% 초과는 빨간 경고이며 저장은 막지 않습니다(B-2). 연차 예산 합계와 연차 예산이 다르면 경고 배지(B-3).
- 부록 B.4: 예산 200,000천원에 집행 188,600천원이면 `94.3%`. 연구재료비 40,000에 43,200이면 `108.0%` 경고.

## 마감·D-day (SOT §6.5)
기준일은 **Asia/Seoul 달력의 오늘**입니다. 서버가 한 번 정해 내려주므로 PC 시계나 타임존이 달라도 같은 판정이 나옵니다.
- 작업: 마감이 지났고 미완료면 **지연**(빨강), `0 ≤ 남은 일수 ≤ 마감 임박 기준일`이면 **임박**(주황).
- 마일스톤: 같은 규칙에 마일스톤 알림 기준일을 씁니다. 완료·취소는 제외합니다.
- 리스크 = `발생확률 × 영향도`. 15 이상 **높음**(빨강), 8~14 **중간**(주황). 해결·종결은 제외합니다.

## 우선순위 (SOT §6.9)
`점수 = 중요도 × 긴급도`(1~25). 중요도만 사람이 정하고 긴급도는 마감일에서 계산합니다.
- 긴급도: 완료 1 / 마감 없음 2 / 31일 이상 1 / 30일 이내 2 / 14일 이내 3 / 7일 이내 4 / 3일 이내 또는 지연 5. 수동으로 고정하면 마감이 바뀌어도 변하지 않습니다(PR-4).
- 등급: 15 이상 **최우선**, 8~14 높음, 4~7 보통, 1~3 낮음.
- 부록 B.0: 중요도 3이라도 지연되면 `3 × 5 = 15`로 최우선이 됩니다.

## 산출근거 (SOT §6.10)
- **인건비**: `연봉 × 참여율/100 × 개월/12 + 조정액`(PL-1). 월액을 먼저 반올림하지 않습니다(PL-2) — 부록 B.7의 `74,000,000 × 28% × 9/12`는 정확히 15,540,000이지만 월액을 반올림하고 계산하면 15,540,001이 됩니다.
- **수량**: `단가 × 인자의 곱 + 조정액`(PL-3). 인자가 없으면 단가 그대로입니다.
- 최종 금액만 정수로 반올림하고(PL-4), 음수는 0으로 자르지 않고 오류로 표시합니다(PL-5).
- 비목 합계는 반올림된 행 금액을 더합니다(PL-8). 산출근거가 있는 셀은 매트릭스에서 직접 고칠 수 없습니다(PL-9).
- 수정인건비 E1 = 인건비에서 연구지원인력인건비 세목을 뺀 값 + 학생인건비(PL-11). 연구수당 비율 = `연구수당 / E1`, 간접비 비율 = `간접비 / 수정직접비`. 부록 B.7 1차년도: `2,000,000 / 207,860,000 = 0.9622%`.

## 규칙 판정 (SOT §6.14)
- 전부 **경고**입니다. 저장·내보내기를 막지 않습니다(RL-1). 판정은 연차 단위이고 정부지원 비율·기관부담 현금 비율만 과제 단위입니다(RL-2).
- 수정직접비 분모는 프리셋에 따라 둘입니다(RL-3): 과기부는 직접비 현금에서 위탁·국제공동·부담비를 빼고, 기후부는 국제공동만 뺍니다. 둘 다 영리기관 간접비 한도는 10%입니다(부록 D).
- 외부 전문기술 비율(RL-7)과 기관부담 현금 비율(RL-9)은 가정이 들어간 **근사**이며 화면에 그렇게 적습니다.
- 분모가 0이거나 총액이 비어 있으면 판정하지 않고 "판정 못 함" 목록에 사유와 함께 남깁니다(B.9.4). 조용히 빠지지 않습니다.
- 비율은 원값으로 한도와 비교하고 표시할 때만 소수 4자리로 반올림합니다. 부록 B.9: 정부지원 `225,000,000 / 325,000,000 = 69.2308%`는 한도 75에서 통과, 67로 바꾸면 위반.
