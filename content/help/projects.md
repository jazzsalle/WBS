# 과제 목록
> 언제 쓰나: 새 과제를 만들거나, 여러 과제를 한눈에 훑고 카드 순서를 정리할 때 씁니다.

## 할 수 있는 것
- 과제 카드에서 색상 띠, 과제명, 부처·전문기관, 진척률 바, 현재 연차 배지, 상태 배지를 봅니다(SOT §7.15).
- `[새 과제]`를 누르면 생성 모달이 열립니다. 이름과 협약 정보를 최소로 입력하면 **단계 1개 + 연차 1개가 자동으로 생성**됩니다(SOT §7.15, §9 createProject). 다년 과제의 나머지 연차는 과제 개요의 단계·연차 타임라인에서 추가합니다(SOT §9 createYear).
- 카드를 **드래그**해 순서를 바꿉니다. 순서는 팀 전체에 같은 값으로 저장됩니다(SOT §7.15, §5.3 order).
- 필터: 상태(기획·수행중·중단·종료·탈락), 아카이브 표시 토글(SOT §7.15, 부록 A.4).
- 아카이브 과제는 기본 숨김이며, 토글을 켜면 흐린 스타일로 함께 보입니다(SOT §7.15).
- 따라하기로 만든 예제 과제는 카드에 `예제` 배지가 붙고 이름이 `[예제] `로 시작합니다(SOT §7.17 TU-3).

## 자주 하는 실수
- **아카이브는 삭제가 아닙니다.** 아카이브는 목록에서 숨기고 대시보드 집계에서 빼는 것이고, 데이터는 그대로 남습니다(SOT §7.2). 실제로 지우려면 과제 개요의 `[과제 삭제]`를 씁니다(SOT §7.3).
- 생성 모달은 단계 1개·연차 1개만 만듭니다. 협약기간이 3년이어도 연차가 저절로 3개 생기지 않으니 개요 화면에서 연차를 추가합니다.
- 현재 연차 배지는 상태가 "수행중"인 연차를 가리키며 과제당 1개만 허용됩니다(SOT §5.5). 새 연차가 시작됐는데 배지가 옛 연차를 가리키면 연차 상태를 바꾸지 않은 것입니다.
- 진척률 바는 저장된 값이 아니라 열 때마다 계산됩니다(SOT §6.1). 작업이 없는 연차도 0%로 평균에 들어가므로(SOT §6.1 P-13), 연차만 미리 만들어 두면 진척률이 낮게 보입니다.
- 상태 필터로 걸러진 상태에서 과제가 안 보인다고 삭제된 것이 아닙니다. 필터와 아카이브 토글을 먼저 확인합니다.

## 관련 계산
- 카드의 진척률은 계산 방식 도움말의 진척률 절을 보세요.
