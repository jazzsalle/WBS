# 백업 폴더 지정·지금 내보내기
> 할 일: 설정의 백업·복원 섹션에서 백업 폴더를 지정하고 `[지금 내보내기]`를 한 번 실행한다.

## 버튼은 어디에
설정(`/settings`) → **백업·복원** 섹션. `[백업 폴더 변경]`으로 폴더를 고른다(데스크톱 앱에서만 가능하며, 구글 드라이브 동기화 폴더를 권장한다). 이어서 `[지금 내보내기]`를 누르면 전 테이블이 JSON 하나로 그 폴더에 저장된다. 브라우저에서는 폴더 대신 다운로드로 받는다.

무료 플랜에는 DB 백업이 없어 이 파일이 유일한 안전망이다. 앱은 마지막 백업이 7일 이상 지났으면 실행 시 자동으로 내보내고 알리며, 백업 파일은 최근 12개를 유지한다. 같은 섹션의 `[복원]`은 파일을 골라 2단계 확인을 거친다.

## 완료되면
이 단계는 앱이 감지하지 못합니다 — 직접 체크하세요. 다만 이 PC에 마지막 백업 시각이 기록되어 있으면 자동으로 완료로 표시된다.
