# 자주 묻는 것
> 언제 쓰나: 백업·충돌·오프라인·키체인·스키마 안내·승인 대기처럼 화면 밖에서 막히는 상황이 생겼을 때 봅니다.

## 왜 백업을 꼭 해야 하나요?
이 앱의 DB는 Supabase 무료 플랜에 있고, 무료 플랜에는 DB 백업이 없습니다(SOT §8.7). 앱이 만드는 JSON 백업 파일이 유일한 안전망입니다. 설정에서 백업 폴더를 지정하면 앱을 열 때 마지막 백업이 7일 이상 지났을 경우 자동으로 내보내고 알리며, 최근 12개를 보관합니다(K-2·K-3). 폴더는 구글 드라이브 동기화 폴더를 권장합니다. 복원은 설정 > 백업·복원에서 하며, 복원 직전 상태를 자동으로 백업한 뒤 2단계 확인을 거칩니다(K-4).

## "OO님이 먼저 수정했습니다"가 떴어요
같은 행을 다른 사람이 먼저 저장한 것입니다. 잠금 대신 마지막에 읽은 버전을 조건으로 저장하기 때문에, 그새 바뀌었으면 저장이 거부됩니다(SOT §8.4). 입력한 내용은 지워지지 않습니다(O-3). `[다시 불러오기]`로 최신 값을 받아 비교하거나 `[계속 편집]`으로 입력을 유지한 채 이어서 고칩니다. 체크박스나 상태 드롭다운처럼 필드 하나만 바꾸는 조작은 이 확인 없이 마지막 값이 이깁니다(O-2).

## 오프라인이면 어떻게 되나요?
네트워크가 끊기면 읽기 전용 배너가 뜨고 저장이 차단됩니다(SOT §8.2 C-4). 오프라인 편집은 지원하지 않습니다 — 연결이 복구된 뒤 다시 시도하세요. 저장이 조용히 실패하는 일은 없습니다(SOT §12).

## 로그인 정보와 HR 키는 어디에 저장되나요?
세션 토큰은 OS 키체인에 저장되고 브라우저 저장소에는 두지 않습니다(SOT §8.2 C-3). 사내 명부 연동용 HR API 키도 같은 키체인에 들어갑니다(SOT §6.13 HR-12). 키는 사용자마다 자기 것을 발급받아 씁니다(HR-10). 키체인은 PC별이므로 **새 PC에서는 로그인과 키 등록을 다시** 해야 하고, 백업 파일에도 키가 들어 있지 않습니다. 앱 배포본에 공용 키를 넣지 않는 이유는 그 키로 누구나 전 직원 명부를 볼 수 있기 때문입니다(HR-11). 데스크톱 앱이 아닌 브라우저에서는 키가 저장되지 않고 이 창에서만 유지됩니다.

## 앱이 안 열리고 "마이그레이션이 필요합니다"라고 떠요
앱은 시작할 때 DB의 스키마 버전을 코드가 기대하는 버전과 비교합니다(SOT §8.8). DB가 **낮으면** 관리자가 저장소를 `git pull`한 뒤 `supabase/migrations`의 마이그레이션을 적용(`npm run db:push`)하고 앱을 다시 시작합니다. DB가 **높으면** 다른 PC에서 새 버전이 배포된 것이므로 앱을 최신 버전으로 업데이트합니다. 마이그레이션 직전에는 자동 백업이 강제됩니다(SOT §8.7 K-6).

## "관리자 승인을 기다리고 있습니다"가 떠요
처음 로그인한 계정은 승인 대기 상태입니다(SOT §7.0, §14.2 A-3). 이미 승인된 사용자 누구나 설정 > 사용자 관리에서 `[승인]`할 수 있습니다(A-5). 승인되면 대기 화면이 자동으로 대시보드로 넘어갑니다. 팀의 첫 사용자는 자동으로 승인됩니다.

## 예제 과제는 어떻게 지우나요?
과제 개요 화면의 `[과제 삭제]`로 지웁니다(SOT §7.17 TU-5). 연쇄 삭제 대상을 안내한 뒤 과제명을 입력하는 2단계 확인을 거칩니다. 따라하기 드로어의 `[예제 과제 지우기]`도 같은 화면으로 보내는 링크입니다. 예제 과제는 실제 DB에 있어 팀 전원에게 보이므로, 다 따라했으면 지우는 편이 좋습니다.

## 인쇄하면 표가 잘려요
인쇄 레이아웃은 기술목표표·리스크 대장·예산 매트릭스 세 화면에 있습니다(SOT §12). 용지는 A4, 여백 12mm이고 방향은 표마다 다릅니다 — 예산 매트릭스와 리스크 대장은 가로, 기술목표표는 세로입니다(P-R1). 인쇄 미리보기에서 방향이 그렇게 잡혀 있는지 확인하세요. 표 머리글은 페이지마다 반복되고 행은 페이지 경계에서 쪼개지지 않습니다(P-R2). 머리말에 과제명과 출력일이 들어가며(P-R3) 버튼·탭은 인쇄물에 나오지 않습니다(P-R4). 다른 화면은 인쇄 레이아웃이 없습니다.
