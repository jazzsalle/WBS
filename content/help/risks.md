# 리스크
> 언제 쓰나: 과제를 위협하는 요인을 발생가능성·영향도로 등급을 매기고 관리대장으로 추적할 때 씁니다.

## 할 수 있는 것
- 상단 5×5 매트릭스에 가로 발생가능성 × 세로 영향도로 리스크 개수가 보입니다. 칸을 누르면 그 칸만 걸러지고 `매트릭스 필터 해제`로 되돌립니다 (SOT §7.11).
- `리스크 추가`로 리스크명·유형(기술·일정·예산·인력·외부·기타)·리스크 내용·발생가능성(1~5)·영향도(1~5)·대응전략(완화·회피·전가·수용)·대응 방안·비상 계획·담당·대응 완료 목표일·상태를 등록합니다 (SOT §5.13).
- 표는 등급(점수) / 리스크명 / 유형 / 발생가능성 / 영향도 / 대응전략 / 담당 / 목표일 / 상태이고, 점수 내림차순이 기본입니다.
- 행을 펼치면 리스크 내용·대응 방안·비상 계획·관련 작업 링크가 보입니다. 연차와 작업에 연결할 수 있습니다.
- 상태는 식별 → 관찰중 → 발생 → 해결 → 종결로 씁니다. 해결·종결 항목은 기본 숨김이고 `해결/종료 표시` 토글로 봅니다 (SOT §7.11).
- 매트릭스는 칸반 화면의 우선순위 매트릭스와 같은 부품입니다. 보는 법이 같습니다 (SOT §7.6).

## 자주 하는 실수
- 점수는 저장되지 않고 발생가능성 × 영향도로 매번 계산됩니다. 등급을 바꾸려면 두 값을 고치세요 (SOT §5.13).
- 대응이 끝났는데 상태를 `해결`이나 `종결`로 바꾸지 않으면 고위험으로 남아 대시보드 "고위험 리스크 수"와 "주의 필요"에 계속 잡힙니다 (SOT §6.5, §7.2).
- 상태가 `발생`이면 점수와 관계없이 대시보드 "주의 필요"에 항상 올라갑니다. 실제로 터진 리스크라는 뜻이므로 대응이 끝나면 `해결`로 넘기세요 (SOT §6.5).
- 관련 작업을 삭제하면 리스크는 남고 작업 연결만 비워집니다. 연차를 삭제해도 리스크는 "연차 없음"으로 남습니다 (SOT §6.6 H-4, H-5).
- 담당자를 삭제하면 리스크는 남고 담당만 비워집니다 (SOT §6.6 H-9).

## 관련 계산
- 점수 = 발생가능성 × 영향도(1~25). 15 이상은 빨간 고위험, 8~14는 주황 중간, 8 미만은 초록입니다. 해결·종결 상태는 등급 판정에서 빠집니다 (SOT §6.5, 부록 A.3).
- 더 자세한 계산은 계산 방식 도움말을 보세요.
