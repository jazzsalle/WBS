# 설정
> 언제 쓰나: 팀이 공유하는 업무 규칙을 바꾸거나, 새 사용자를 승인하거나, 백업을 만들고 되돌리거나, 사내 명부 연동 키를 등록할 때 씁니다.

## 할 수 있는 것

### 팀 설정
팀 전체가 공유하는 규칙 6가지입니다(SOT §5.16). 저장하면 모든 사용자에게 바로 적용됩니다.
- **마감 임박 기준일** — 기본 7일. 작업 마감이 이 날수 안이면 "임박"으로 표시합니다(SOT §6.5).
- **마일스톤 알림 기준일** — 기본 30일. 마일스톤이 이 날수 안이면 "예정"으로 표시합니다.
- **주 시작 요일** — 기본 월요일.
- **간트 기본 스케일** — 기본 주 단위. 간트 화면에서 개인이 바꾼 스케일은 자기 PC에만 남습니다.
- **표시 통화 단위** — 원·천원·백만원, 기본 천원. 저장은 언제나 원 단위 정수이고 표시만 바뀝니다(SOT §6.4 B-4).
- **진척률 가중 기준** — 기본 예산 가중. 연차·단계 진척률을 예산으로 가중할지 균등으로 볼지 정합니다(SOT §6.1).

### 사용자 관리
- 승인 대기자는 상단에 뱃지와 함께 보이며 `[승인]`으로 들여보냅니다. 역할 구분이 없어 승인된 사용자는 누구나 대기자를 승인할 수 있습니다(SOT §14.2 A-3·A-5).
- 활성 사용자는 본인을 제외하고 `[비활성화]`할 수 있습니다.
- 내 프로필(표시 이름, 참여인력 연결)도 여기서 고칩니다.

### 백업·복원
- `[지금 내보내기]` — 전 테이블을 JSON 한 파일로 백업 폴더에 저장합니다(SOT §8.7 K-1). 마지막 백업 시각과 자동 백업 상태가 옆에 보입니다.
- 자동 백업은 앱을 열 때 마지막 백업이 7일 이상 지났으면 실행되고 알립니다(K-2). 백업 폴더가 지정된 데스크톱 앱에서만 돕니다.
- 백업 파일은 최근 12개를 유지합니다(K-3). 폴더는 온보딩에서 지정하며 구글 드라이브 동기화 폴더를 권장합니다(SOT §14.4). 여기서 바꿀 수 있습니다.
- `[복원]` — 파일을 고르고 2단계 확인을 거칩니다. 복원 직전 상태가 자동으로 백업됩니다(K-4). 전체 대체만 있고 부분 복원·병합은 없습니다(K-7).
- 엑셀 임포트 스냅샷 목록과 복원도 이 섹션에 있습니다.

### 사내 명부 연동
- HR API 키를 붙여넣고 `[연결 확인]`으로 성공 여부와 인원 수를 확인합니다. 저장 뒤에는 끝 4자리만 보입니다. 발급은 `hr.unes.kr 로그인 → API 키 → 용도 입력 → 이메일 인증` 순서이며 키는 발급 화면에서 한 번만 보입니다(SOT §7.14).
- 키는 OS 키체인에만 저장되고 앱 DB·백업 파일에 들어가지 않습니다(SOT §6.13 HR-11·HR-12). 그래서 **PC마다 각자 등록**해야 합니다. 데스크톱 앱이 아니면 "이 창에서만 유지됩니다"로 표시됩니다.

### 따라하기 다시 열기
따라하기 드로어를 "다시 보지 않기"로 닫았다면 여기서 되돌립니다(SOT §7.17 TU-1).

## 자주 하는 실수
- **백업 폴더를 지정하지 않음** — 자동 백업이 "꺼짐"인 채로 남습니다. 무료 플랜에는 DB 백업이 없으므로 이 파일이 유일한 안전망입니다(SOT §8.7).
- **다른 스키마 버전의 백업으로 복원** — 거부됩니다(K-5). 앱과 DB 버전을 먼저 맞추세요.
- **복원을 "일부만 되돌리기"로 생각함** — 복원은 팀 데이터 전체를 그 파일 내용으로 바꾸고 모든 사용자에게 즉시 반영됩니다. 사용자 목록과 스키마 버전은 되돌리지 않습니다(K-8).
- **HR 키를 백업에서 찾음** — 키는 백업에 없습니다. 새 PC에서는 다시 등록해야 합니다.
- **통화 단위를 바꾸면 금액이 바뀐다고 생각함** — 표시만 바뀝니다. 입력·저장은 원 단위 그대로입니다.

## 관련 계산
- 마감 임박·마일스톤 알림 기준일이 판정에 쓰이는 방식은 계산 방식 도움말의 "마감·D-day" 절을 보세요.
- 진척률 가중 기준(예산/균등)과 폴백 규칙은 계산 방식 도움말의 "진척률" 절을 보세요.
